# Smart irrigation images

All the images used by the Smart irrigation panel (`layouts/irrigation.js`); paths are set in `projects.js`.

- `sketch.png`: pencil sketch from the report cover
- `tile-*.png`: component cut-outs shown inside the cover's diamonds
- `evapotranspiracio.png`, `et-*.png`: the evapotranspiration diagram and its four factors
- `working.png`, `logica.png`, `components.png`, `prototype.jpg`, `final.png`: the prototype
- `award-*.jpg`: award photos, already toned to warm black and white
